Plan the run you actually want.

RunWay builds running routes from OpenStreetMap and weights them the way you run — away from traffic lights, through parks, flat or hilly, lit or not. Describe the run in a sentence and it works out the rest.

What makes it different

Most planners route you like a car with the engine off. RunWay has its own cost function over the raw street graph, so the things runners care about are actual routing inputs.

Connect a backend

RunWay works fully without one — accounts, routes and plans all live in this browser. Connecting a Supabase project adds real accounts, sync across your devices, and a community where you can actually see other runners' public routes.

Not yet verified. The Supabase integration is written against the documented API but has never been run against a live project. Try it on a throwaway project first.
Setup, in order. Create a free project at supabase.com → open the SQL Editor → paste and run supabase/schema.sql from this folder → copy your project URL and anon key from Project Settings → API → paste them here.

Supabase project

The anon key is a public key and is meant to be visible in the browser. Row-level security in the schema is what protects the data.
